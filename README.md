Версия Unreal Engine: 5.7.4
Проект не проверялся на реальном VR-устройстве, для проверки использовалось приложение Meta XR Simulator.

ЗАПУСК:

Для открытия проекта необходимо:
1. Клонировать репозиторий с помощью IDE, GitHub Desktop или другим способом;
2. Нажать правой кнопкой мыши на файл с расширением .uproject и выбрать generate Visual Studio project files;
3. Открыть появившийся файл с расширением .sln с помощью IDE и собрать проект;
4. После сборки и открытия проекта, в дальнейшем, проект может быть запущен с помощью файла с расширением .uproject, без сборки через IDE.

Для сборки и запуска проекта в VR-режиме необходимо:
1. Открыть проект;
2. Выбрать в левом верхнем углу меню Platforms -> Package Project -> Package for: выбрать необходимую платформу, Build configuration: Shipping;
3. В этом же меню нажать на Package Project, выбрать расположение и дождаться окончания сборки;
4. По окончании сборки, перейти в выбранное ранее расположение и запустить исполняемый файл, актуальный для выбранной ранее платформы;
5. При предварительном подключении VR к устройству, проект запустится в VR-режиме автоматически.

УПРАВЛЕНИЕ:

Левый контроллер:
	* Движение стика - перемещение фокуса в VR UI если он открыт, поворот на 45 градусов влево или вправо если VR UI закрыт;
	* Нажатие на стик - нажатие на кнопку в VR UI;
	* Нажатие и удержание кнопки триггера - открытие VR UI;
	* Нажатие и удержание кнопки на рукоятке - перемещение в пространстве по траектории.
Правый контроллер:
	* Движение стика - вращение удерживаемого интерактивного объекта;
	* Нажатие на стик - сброс вращения удерживаемого интерактивного объект;
	* Нажатие триггера - взять интерактивный объект, на который наведен луч трассировки;
	* Нажатие и удержание кнопки на рукоятке - активировать луч трассировки для взаимодействия с интерактивными объектами.

АРХИТЕКТУРА:

Основные C++ классы и их ответственность:
1. InteractiveActor:
	* Базовый класс интерактивного объекта, наследник StaticMeshActor;
	* Любой объект такого класса или являющийся его наследником определяется системой как интерактивный;
	* Содержит данные о своем состоянии, типе, имени, описании и весе;
	* Содержит метод для изменения состояния объекта (Free - объект свободен, Hovered - на объект наведен луч пользователем, Held, объект удерживается пользователем).
2. InteractiveActorSmall и InteractiveActorLarge:
	* Наследники InteractiveActor, представляющие из себя типы интерактивных объектов;
	* От них наследуются интерактивные объекты, непосредственно размещаемые на уровне;
	* Для добавления нового типа интерактивного объекта следует создать новый объект, унаследованный от InteractiveActor и дать ему описание его типа.
3. InteractiveActorFunctions:
	* Библиотека функций, содержащая методы для создания и удаления интерактивных объектов на уровне.
	
Основные Blueprint классы и их ответственность:
1. XRPawn:
	* Класс контролируемый пользователем;
	* Принимает ввод от контроллеров и шлема;
	* При помощи луча трассировки из правого контроллера позволяет взаимодействовать с объектами, являющимися наследниками InteractiveActor;
	* Позволяет добавить на уровень новый интерактивный объект или удалить имеющийся с помощью методов из InteractiveActorFunctions;
	* При добавлении объекта, добавлен будет объект типа, выбранного в VR UI;
	* При удалении объекта, удален будет объект удерживаемый пользователем. Если такого нет, то удален будет объект, на который наведен луч трассировки.
2. VR UI:
	* Появляется возле левого контроллера при нажатии определенной кнопки на контроллере;
	* Отображает данные объекта, на который наведен луч трассировки или который удерживается пользователем, данные о котором передает XRPawn;
	* Отображает данные об общем количестве интерактивных объектов на уровне;
	* Содержит кнопки для добавления и удаления интерактивных объектов на уровне (данные об объектах, доступных для создания передает XRPawn).
